## One finite end-to-end checklist

- [ ] Schema / safe migration / restore for client-scoped site contacts, permissions and retention.
- [ ] OWNER/ADMIN and client edit/read; tampered URL/action and staff-only assignment denial.
- [ ] Visit-scoped projection, safe access-note handling, exact tenant contact permission and COM-L SMS-deny proof.
- [ ] Tenant report → correct client's maintenance + client notification; damage requires separate authorization.
- [ ] Tenancy turnover, configurable automatic PII erasure, no rental/billing side effect.
- [ ] Bulk row validation, preview, duplicate detection, all-or-nothing import.
- [ ] Adversarial DB/role/replay/browser/migration/restore tests and full exact-head CI/review.
