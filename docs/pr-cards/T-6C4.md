## Build contract

New tax/rdf-filing.ts: buildRdfPacketInTx(tx:Prisma.TransactionClient,periodId:string):Promise<RdfPacket>; reserveRdfCreditsInTx(tx,periodId,recordIds:string[]):Promise<void>. RdfPacket typed {version:1; periodId:string; deliveries:number; rows:{rateId:string; amountCents:number; count:number; totalCents:number}[]; priorPeriodCreditCents:number; taxDueCents:number;sourceRecordIds:string[];creditRecordIds:string[];blockers:string[]}.
Filing date is deliveredOn; amount by saleOn. Incomplete fee records block packet, never disappear; zero returns allowed. Use existing period/account lock/frozen worksheet/hash/mark-filed path with a discriminated packet kind; don't fabricate sales tax rows. Under filing lock reserve eligible prior-period credits; collected fee requires confirmed full customer refund before credit; PAY_MYSELF needs none. Credit can belong to one open packet; frozen filed credit cannot reuse. A read-only preview does not reserve/alter records. Added positive liability to filed period uses amendment; over-report uses later return credit, not duplicate amendment. Signed source corrections stay auditable.
Missing applicable handling/CPA confirmation joins readiness. Setup/reminders/June rate-entry/80-percent threshold notices share SALES_TAX attention; no separate cron. Confirm packet union compatibility with existing sales/use callers/tests.
