# W-8 and W-9 — simpler menu with plain-words check, and the tax filing autopilot (approved original subsections)
Source: docs/designs/BATCH-W.md D-W6, D-W7 (W-8) and D-WA1 (W-9); docs/PLAN.md remaining acceptance; docs/designs/OWNER-DECISIONS-2026-10-13-ENGINEERING.md. Prerequisite W-7 merged (#483).
One coherent outcome: the owner opens a short, plainly worded desk and never has to wonder what to file, how much to pay, or whether a return was missed.

## Frozen original complete acceptance
### W-8
- The desk menu has these 14 entries: Today, Tasks, Leads, Customers, Quotes, Communications, Rentals, Schedule, Repairs, Equipment, Money, Taxes, Settings and More. Owner and admin see all 14, staff see only the ones they can open, and the phone bottom bar uses the same names as the menu.
- Dispatch, Jobs and Driver view are one Schedule entry with three views; Parts, Purchases and Purchase orders are tabs under Equipment; Revenue, Fleet, Reports and Business overview are tabs under Money. Every old address still opens, and the right menu entry stays highlighted on each.
- Suppliers, Growth signals, Launch list, System health, Privacy requests and Activity are on a More page that lists only what the signed-in role may open (enforced where the list is built); developer-only screens such as the preview storage check are not in the owner's menu or on More.
- A plain-words check runs with the lint step in CI: a reviewed list of banned phrases (such as taxability matrix, remit, election, cents, raw status codes, jurisdiction) is refused on owner screen text with a plain replacement shown, any allowlist entry needs a written reason, and the wording it finds today is fixed.
- Every menu entry, tab and More link opens a page that exists, checked against the route list for owner, admin and staff.
### W-9
- On the day a filing period closes, Today shows "File and pay $X on <site> by <date>" (or "File a $0 return on <site> by <date>", because a $0 return still has to be filed), with "(overdue)" after the legal deadline, and it opens that return.
- Owner reminder emails go out the owner-chosen days before the due date (starting 7 and 2), on the due day, and every business day while the return is overdue.
- "I filed and paid it" asks only for the date paid and the confirmation number; the filed date and a different amount are optional extras (a different amount still needs a reason). Saving it locks the return and marks the equipment use tax on it as filed.
- A nightly check raises a high-priority System health issue when a closed filing period has no return on the list, and clears it once the return exists, so nothing is ever left silently unfiled.

## Gates and exclusions
No Stripe LIVE, customer email, SMS, spending or production fixtures. The app still never files a return or pays tax: the owner presses Submit and pay on the official site (D-WA2: no robot submission). W-10 and later units are not part of this bundle.

## Engineering decisions (not owner policy)
- No screen moves: tabs are layouts that link existing addresses, so every bookmark and link keeps working (the old addresses are the new addresses).
- The To do amount comes from the same filing packet the return page uses (first 12 open returns); if a packet is blocked the older "<account> return due" wording stays so Today never fails to load.
- Overdue reminder emails become daily (business days) to match the approved D-WA1 schedule; the before-due days stay the existing owner-editable per-account setting (starting 7 and 2).
- "Filed date" defaults to the date paid and the amount defaults to the calculated amount; a different amount still needs a written reason, and the confirmation number is always required.
- The missing-period check compares every active filing account's calendar with its saved periods and uses the existing System health list.
- The preview storage check is already off the menu and returns "not found" outside test storage; the new tests lock that in.
